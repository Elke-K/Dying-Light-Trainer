# Dying-Light-Trainer
This is a heavy work in progress. Crashes still happen and more checks are still needed.


# How to use

Make sure you own dying light 1. Then if you want to display names, you'll have to get the "common_texts_all.bin" file from DW/DataEn/data/maps/common_texts_all.bin. use a bin editor for dying light 1 to make it into a txt file and then rename it to Common.txt inside the dying-light-trainer folder from the repo.
